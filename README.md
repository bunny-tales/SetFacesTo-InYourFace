Set Faces To In Your Face, is a VSCode extension that shows your Favorite 'Uncanny Faces' that correlate to the number of errors in your code!

![Loading...](https://i.postimg.cc/x1Txd1Mw/Set-Faces-To.png)

Once the extension is installed, go to the VS Code settings and provide the path to the images that the extension should use to replace the default images for each detected error.

![Loading...](https://postimg.cc/tZ840r8k)

Restart VS Code, and it should work.

![Loading...](https://postimg.cc/py2HrMJY)
